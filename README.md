# Virtuelle Deutschlandreise – German A1

Week 4 internship project: a 60-minute virtual field trip to five German landmarks.

Stops: Brandenburg Gate, Cologne Cathedral, Neuschwanstein Castle, Heidelberg Castle and Zugspitze.

Features:
- Virtual itinerary
- Cultural landmark cards
- A1 vocabulary
- Interactive speaking prompts
- Favourite landmark reflection
- Culture quiz
- Responsive lightweight design

Run by opening `index.html` or using VS Code + Live Server.
